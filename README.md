Automação de Envio de Relatórios via e-mail
O que faz: Um script que abre o navegador, coleta os dados necessários, faz o calculo de: Faturamento Total, Quantidade de produtos vendidos e Faturamento de uma filial em especifico e realiza o envio automático dos dados analisados via e-mail.
Ferramentas:Python, PyAutoGUI, Pandas e Pyperclip.
