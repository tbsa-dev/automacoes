Automação de Envio de Relatórios via e-mail
O que faz: Um script que abre o navegador, coleta os dados necessários, faz o calculo de: Faturamento Total, Quantidade de produtos vendidos e Faturamento de uma filial em especifico e realiza o envio automático dos dados analisados via e-mail.

Automação para exclusão de e-mails.
O que faz:
Script desenvolvido em Python utilizando a biblioteca pyautogui para automatizar a navegação e a limpeza de caixas de entrada. O programa interage com o sistema operacional para abrir o navegador, acessar o link informado, realizar a busca por uma palavra-chave específica e executar a exclusão em lote dos e-mails de forma contínua (Ainda irá ter melhorias). 

Automação de cadastros em site
O que faz: Automatiza o processo de login em sistemas web e o preenchimento de formulários de cadastro de produtos. O script lê uma base de dados estruturada e executa as inserções de forma contínua até registrar todos os itens informados, otimizando o tempo e reduzindo erros manuais.
